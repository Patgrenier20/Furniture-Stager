# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include secrets, private images, or personal information in a report.

Use the repository's private security advisory flow on GitHub:

1. Open the repository's **Security** tab.
2. Choose **Advisories**.
3. Select **Report a vulnerability**.

Include the affected component, reproduction steps, likely impact, and any suggested mitigation. Remove credentials and personal data from screenshots and logs.

## Supported versions

FurniFlip is an early-stage project. Security fixes target the current default branch; older commits and forks are not maintained.
